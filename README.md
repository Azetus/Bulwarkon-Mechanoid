# Bulwarkon Mechanoid (堡垒盾卫)

一个《边缘世界》游戏 Mod，为游戏添加一个名为"堡垒盾卫"的重型支援机械体——拥有全角护盾、可部署护盾投影仪和治愈烟雾发生器。

## 主要功能

- 新增机械体"堡垒盾卫"：无武器、纯防御定位，通过大型机械培育器制作
- 自身全角护盾：拦截地面和空中投射物，盾量、恢复速度、半径等参数可在 Mod 设置中调整
- 技能 1「部署护盾投影仪」：原地部署区域护盾，3 次充能，消耗护盾核心或高级零部件装填
- 技能 2「部署治愈烟雾发生器」：原地部署治愈烟雾，包扎伤口止血并缓慢恢复生命值，3 次充能，消耗闪耀世界医药或普通医药装填
- 医疗能力：15 级医疗技能，100% 工作效率，仅可从事医生工作
- 装填弹药类型可在 Mod 设置中切换（护盾核心 ↔ 高级零部件 / 闪耀世界医药 ↔ 医药）
- 烟雾范围内防火：进入烟雾的 pawn 免疫火焰
- 全部参数可在 Mod 设置中实时调整，无需重启

## 需求

- Biotech DLC 和 Royalty DLC

## 注意事项

1. 堡垒盾卫不会在机械体袭击中出现，仅可通过大型机械培育器制作
2. 堡垒盾卫无法装备武器，仅能通过近战拳击自卫（近战攻击力极低）

## 兼容性

- 提供 Combat Extended 兼容补丁（护甲值、近战工具均已适配 CE 系统）
- 理论上兼容其他 Mod

## FAQ

**Q: 可以中途加入存档吗？**  
A: 可以。如果已研究 UltraMechtech 科技，大型机械培育器中会出现制作配方。

**Q: 可以中途移除吗？**  
A: 如果存档中没有已存在的堡垒盾卫，可以安全移除。

# Bulwarkon Mechanoid

A RimWorld mod that adds a heavy support mechanoid called the "Bulwarkon" — equipped with a full-angle shield projector and the ability to deploy
portable shield projectors and healing smoke generators.

## Features

- New mechanoid "Bulwarkon": weaponless, pure defense, crafted at the large mech gestator
- Built-in full-angle shield: intercepts ground and air projectiles; shield HP, regen speed, and radius adjustable in Mod Settings
- Ability 1 "Deploy Shield Projector": places an area shield on the ground, 3 charges, reloaded with shield cores or advanced components
- Ability 2 "Deploy Healing Smoke Generator": places a healing smoke emitter, tends wounds and slowly heals injuries, 3 charges, reloaded with
  glitterworld medicine or regular medicine
- Medical capability: skill level 15, 100% work speed, doctor work only
- Reload ammo type switchable in Mod Settings (shield core ↔ advanced component / glitterworld medicine ↔ medicine)
- Fire immunity within smoke: pawns under smoke effect cannot catch fire
- All parameters adjustable in Mod Settings in real time — no restart required

## Requirements

- Biotech DLC and Royalty DLC

## Notes

1. Bulwarkon does not appear in mechanoid raids — only obtainable via large mech gestator
2. Bulwarkon cannot equip weapons; melee punches only (extremely low damage)

## Compatibility

- Combat Extended compatibility patch included (armor values and melee tools adapted for CE)
- Theoretically compatible with other mods

## FAQ

**Q: Safe to add mid-save?**  
A: Yes. The crafting recipe will appear in the large mech gestator if UltraMechtech is researched.

**Q: Safe to remove mid-save?**  
A: Yes, if no existing Bulwarkons are present in the save.
